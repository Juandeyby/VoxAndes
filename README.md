# CHINCANA - Voxel Adventure Game

![Banner Image](URL_DE_TU_BANNER_AQUI)

**An Inca-inspired psychological horror exploration game** developed solo over 5 months in my spare time.

## 🏔️ Project Highlights
- First-person voxel exploration
- Dynamic torchlight system
- Culturally accurate Inca environments
- Psychological horror elements
- Fully solo developed (design/code/art)

## 🎮 Controls
| Key | Action |
|------|--------|
| WASD | Movement |
| C | Interact |
| Left Click | Attack |
| Shift | Sprint |

## 📥 Installation
1. Download latest release
2. Extract ZIP file
3. Run `Chincana.exe`

## 🛠️ Technical Features
- Custom lighting shaders
- Physics-based interactions
- Adaptive sound design
- Optimized for WebGL/PC
